# Task 7: Basic Sales Summary using SQLite and Python

## 🎯 Objective
This project is part of a Data Analyst Internship and aims to demonstrate how to:
- Connect Python to an SQLite database.
- Run basic SQL queries using `sqlite3`.
- Perform data summarization with `pandas`.
- Visualize results using `matplotlib`.

---

## 🗂 Files Included
- `sales_summary` – Connects to the database, summarizes data using SQL, and generates a bar chart.
- `sales_data.db` – SQLite database file with a `sales` table.
- `sales_chart.png` – Bar chart showing revenue by product.
